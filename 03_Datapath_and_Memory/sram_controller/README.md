# SRAM Controller

## What this does
A single-port SRAM controller implemented in Verilog HDL. The design uses a finite state machine (FSM) to manage read, write, and idle operations while generating handshake signals such as `ready` and `write_en`. The controller interfaces between a processor or master and an external SRAM memory block.
