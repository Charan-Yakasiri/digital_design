# 32×32 Register File

## What this does
A 32-register × 32-bit register file with one synchronous write port and two asynchronous read ports, commonly used in RISC-V and MIPS processor datapaths.

## Files
| File | Description |
|------|-------------|

| waveform.png | Simulation waveform |
| register_file_mapped.v | Technology-mapped netlist generated by Yosys |

## What I learned
- Learned how register files provide fast access to multiple operands using dual-read and single-write ports.
- Understood how write enable and address decoding control which register is updated on the clock edge.
- Verified the synthesized design using a technology-mapped netlist and confirmed zero timing violations with OpenSTA.
