# Digital Design Portfolio

> Structured proof of RTL, FPGA, and digital design skills.
> Every folder = a skill. Every subfolder = a working implementation.

## Folder Map

| Folder | Skills Demonstrated | Tools |
|--------|--------------------|----|
| 01_RTL_Fundamentals | Verilog HDL, Sequential & Combinational Logic | Vivado, ModelSim, GTKWave |
| 02_FSM_Design | Moore FSM, Mealy FSM, One-hot encoding | Vivado, iVerilog |
| 03_Datapath_and_Memory | ALU, FIFO, SRAM, Register File | Vivado, Verilator |
| 04_Protocols | UART, SPI, I²C, AXI4-Lite | Vivado, VSDsquadron board |
| 05_CDC_and_Timing | Clock Domain Crossing, Async FIFO, Reset Sync | Vivado STA, Timing Reports |
| 06_FPGA_Implementation | XDC Constraints, Fmax, Board Demo | Xilinx Vivado, Spartan-7/VSDsquadron |

## Each implementation includes
- RTL source code (.v / .sv)
- Self-checking testbench
- GTKWave / ModelSim waveform screenshot
- Synthesis report (LUT, FF, BRAM utilisation)
- Timing report (Fmax, setup/hold slack) where applicable
